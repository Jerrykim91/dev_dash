## 발견하여 수정한 문제

- Phaser 카메라 속성은 상속 접근자이므로 객체 spread가 치수를 보존하지 않았습니다. 줌 후 scroll이 NaN이 되는 문제를 명시적 CameraView 생성으로 수정하고 상속 접근자 회귀 테스트·실제 wheel/pinch 유한성 검사를 추가했습니다.
- 관리자 메뉴 전환 때 이전 메뉴의 배열을 새 로그 형식으로 렌더링하는 순간 오류가 발생했습니다. 선택 시 데이터 초기화·비활성 비동기 응답 무시·시간 형식 guard로 수정했습니다.
- 채널 입장이 거부되면 채널 선택도 잠기는 문제를 수정했습니다. 미연결 상태의 채널 목록/선택 재접속을 추가했습니다.
- 비활성 채널에 저장된 좌표를 기본 채널에 적용하던 문제를 수정했습니다.
- 모바일에서 두 번째 캐릭터를 클릭하면 프로필이 열리는 정상 동작에 맞춰 기존 이동 테스트의 바닥 위치를 분리했습니다. 설정/모드 선택자도 새로운 모바일 UI에 맞췄습니다.
- 테스트 클러스터는 처음 재시작 시 일회성 포트 옵션을 잃었습니다. 임시 클러스터 자체 설정에 loopback·포트·socket 경로를 저장한 후 재시작·복원을 다시 통과했습니다. 앱/Compose 결함과 구분합니다.

## 미검증·잔여 제한

- **Docker 엔진 없음**: Compose config CLI/이미지 빌드/서비스 기동·컨테이너 재시작·Docker 볼륨 보존·컨테이너 pg_restore·Nginx WS 프록시 실제 실행은 미검증입니다. YAML·이미지 manifest·native DB 성공을 이 항목의 완료로 보고하지 않습니다.
- Ubuntu/Debian apt 설치 명령과 실제 Raspberry Pi 4 8GB 성능·장시간/다중 채널 부하는 미검증입니다. `infra/verify-arm64.sh`와 README에 대상 서버 실행 순서를 제공합니다.
- 실제 운영 도메인/TLS/외부 DevNest 서버는 미제공입니다. 운영 기본 URL은 비워 두며 로컬 기본값을 내보내지 않습니다. 다른 origin의 페이지 성공/장애는 자동 탐지하지 않고 새 탭 확인·재시도·URL 설정 안내를 제공합니다.
- Vite 번들 약 1.78MB(gzip 약435KB) 경고, Python 3.14에서 기존 FastAPI/Starlette 사용 중 deprecation 경고가 있습니다. 테스트 실패는 아니며 로딩 최적화와 런타임 업데이트는 후속 과제입니다.
- 실시간 Hub는 단일 프로세스입니다. PG 트랜잭션 직렬화와 매 작업 연결 방식의 Pi 부하는 측정 전입니다. 다중 worker·분산 접속 정원은 지원하지 않습니다.
- 최종 아트·소셜 피드·미니게임·보상·결제·타인 집 방문·외부 일정·음성/영상은 추가하지 않았습니다.
