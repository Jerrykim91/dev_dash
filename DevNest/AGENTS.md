# DevNest 개발 지침

- HTML, CSS, Vanilla JavaScript를 사용한다. Raspberry Pi 4를 고려해 외부 런타임 의존성을 최소화한다.
- 이미지 자산은 frontend/assets에, UI 코드는 HTML/CSS/JS에 분리한다.
- 제공된 A 시안의 어두운 보라색 픽셀 오피스 스타일을 유지한다.
- 실제 제공된 캐릭터 스프라이트를 사용한다. 자산이 없거나 투명도에 문제가 있으면 임의로 대체하지 말고 보고한다.
- 캐릭터 외형과 상대 배치를 유지하고 반응형 및 키보드 조작을 고려한다.
- 현재 범위는 프런트엔드다. FastAPI, DB, 실제 API 연동은 별도 요청 시 진행한다.
