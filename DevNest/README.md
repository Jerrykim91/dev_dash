# DevNest — Pixel Office & Customizable Widgets

HTML / CSS / Vanilla JavaScript로 구현한 A 시안의 보라색 픽셀 대시보드입니다. 라이브러리, DB, 실제 API 연동은 없습니다.

## 로컬 실행 방법

DevNest는 별도 패키지 설치 없이 Python의 정적 파일 서버로 실행할 수 있습니다.

1. macOS에서 터미널을 엽니다.
2. 아래 명령을 그대로 실행합니다.

```bash
cd /Users/hyowonkim/Desktop/Demo/Projects/DevNest/frontend
python3 -m http.server 8000 --bind 127.0.0.1
```

3. 브라우저에서 [http://localhost:8000](http://localhost:8000)에 접속합니다.
4. 헤더의 톱니바퀴 버튼을 누르면 오피스·업무 상태·애니메이션·위젯 설정을 변경할 수 있습니다.

서버를 종료하려면 명령을 실행한 터미널에서 `Ctrl+C`를 누릅니다. 현재 단계는 프런트엔드만 실행하므로 FastAPI, 데이터베이스 또는 추가 라이브러리를 설치할 필요가 없습니다.

설정은 브라우저의 `localStorage`에 저장됩니다. 같은 주소와 포트로 다시 접속하면 이전 설정이 복원됩니다. 수정된 이미지나 코드가 바로 보이지 않으면 macOS 기준 `Cmd+Shift+R`로 강력 새로고침하세요.

> HTML 파일을 Finder에서 직접 열지 말고 위 명령으로 로컬 서버를 실행하는 방식을 권장합니다.

## 세 요소의 배치

개발자, 고양이, 노트북, 여섯 화분과 네 책상 소품 모두 별도 `.actor` Wrapper를 사용합니다. 외부 Wrapper는 위치·크기, 내부 Sprite는 프레임 애니메이션을 담당합니다.

| 요소 | 기본 X | 기본 Y | 기본 너비(장면 대비) | Scale |
| --- | --- | --- | --- | --- |
| 개발자 | 43% | 63.7% | 22% | 1 |
| 노트북 | 51.5% | 64.4% | 17% | 1 |
| 고양이 | 64.5% | 64.4% | 13% | 1 |

노트북은 개발자 손 앞, 고양이는 노트북 오른쪽에 배치합니다. 기본 Z-index는 개발자 2 → 노트북 3 → 고양이 4입니다. 각 설정의 ‘겹침 순서’에서 2~20으로 변경·저장할 수 있습니다. 실제 UI 배지는 객체보다 앞에 유지됩니다. 편집 중 선택 대상을 잠시 앞으로 가져오지만 저장된 순서를 바꾸지는 않습니다. 노트북 크기는 개발자 얼굴을 가리지 않도록 맞췄습니다. 손 동작은 원본 해상도에서 번갈아 10픽셀씩 들어 올리며 몸통은 고정됩니다. 노트북의 크기·위치에 따라 손 일부는 가려질 수 있어 설정에서 노트북을 오른쪽으로 옮겨 조절할 수 있습니다.

- 좌표 기준은 실제 오피스 장면의 이미지 캔버스 **하단 중앙**입니다. 브라우저나 카드의 바깥 여백은 포함하지 않습니다.
- `x`, `y`는 0~100%, `scale`은 0.5~2배, `visible`은 표시 여부입니다.
- `actor-assets.js`에서 실제 자산의 비율과 기본 너비를 공유합니다. 요소별 가로·세로 비율을 고려해 전체 캔버스가 장면 밖으로 나가지 않도록 좌표를 보정합니다.
- 설정의 세 요소 X/Y, 숫자 크기와 크기 슬라이더는 즉시 반영·동기화됩니다.
- ‘위치 편집’을 켜고 대상 목록에서 개발자·고양이·노트북을 선택해 드래그합니다. 선택 대상은 편집 중 앞에 표시되어 겹쳐 있어도 조절할 수 있습니다.
- Pointer Events / pointer capture로 마우스·터치를 지원합니다. 방향키는 1%, Shift+방향키는 0.1%씩 이동합니다.
- 드래그 중에는 실시간 메모리 갱신, 종료·취소 시 저장합니다. 다른 입력은 변경 즉시 저장합니다.
- 숨긴 요소도 편집 중에는 반투명하게 표시합니다. 편집 종료 후 정상 표시·애니메이션으로 복원됩니다.
- ‘기본 위치 복원’은 세 요소의 위치·크기·표시 여부를 초기화합니다. 이미 저장한 위치는 자동으로 기본값으로 덮어쓰지 않습니다. 새 기본 배치를 원하면 이 버튼을 사용하세요.

일반 화면은 책상 위 보기로 고정하며 위치 편집 중에만 전체 장면을 표시합니다. 현재 표시된 실제 장면의 `getBoundingClientRect()`로 포인터 좌표를 변환합니다. 이미지 비율을 왜곡하지 않습니다. 배경에는 의자가 있고 임의 위치에서는 캐릭터와 겹칠 수 있습니다. 배경 가구 충돌 회피는 하지 않고 장면 외곽만 제한합니다.

## 저장과 상태

`settings-store.js`는 저장 어댑터와 검증·마이그레이션을 UI에서 분리합니다. 현재 키는 `devnest.settings`, 버전은 **21**입니다.

- `office.developer`, `office.cat`, `office.laptop` 각각 X/Y/scale/visible/zIndex를 저장합니다.
- 버전 2/3의 기존 위치·크기·표시 여부를 보존하고 Z-index 및 애니메이션 세부 항목을 보충합니다. 노트북이 없는 저장 형식에는 개발자 위치를 기준으로 추가합니다.
- 이전 왼쪽 좌표/너비 형식은 하단 중앙/scale로 변환합니다. 잘못된 JSON은 기본값, 잘못된 필드는 개별 기본값으로 복구합니다.
- 저장소 접근·용량 오류는 화면에 명시하고 메모리에서는 계속 동작합니다.
- 저장된 설정의 포트/호스트가 다르면 다른 저장소입니다. 파일 직접 열기보다 위 정적 서버 실행을 권장합니다.

`setOfficeState(state)`와 설정의 실제 업무 상태는 계속 동작합니다.

| 상태 | 장면 |
| --- | --- |
| `before_work` | 개발자 숨김, 고양이·노트북 유지 |
| `working` | 개발자 타이핑, 고양이 수면, 노트북 정적 |
| `overtime` | 개발자 타이핑·다크서클, 고양이 수면, 노트북 열림 |
| `meeting` | 자리 비움: 개발자 숨김, 고양이 위치 변경, 닫힌 노트북·안내판 / 화상: 참가자 화면 |
| `after_work` | 개발자 숨김, 노트북 OFF·어둡게, 고양이 수면 |
| `holiday` | 개발자 숨김, CLOSED·노트북 어둡게, 고양이 수면 |

미리보기는 실제 상태를 바꾸지 않으며 종료·설정 닫기 시 현재 실제 상태로 복원됩니다. 상태 전환은 저장된 좌표를 초기화하지 않습니다. 실제 업무 상태는 저장되어 새로고침 후 복원됩니다.

정적/애니메이션 표시 모드, 전체 활성화, 손·눈·고양이 개별 활성화, 날씨 활성화, 0.5~2배 속도, `prefers-reduced-motion`을 유지합니다. 동작 줄이기 시 개발자·고양이를 정지 이미지로 표시하고 추가 비 효과를 끕니다. 원본 배경에 그려진 정적 빗줄기는 남습니다.

### 헤더 업무 상태 선택

헤더의 업무 상태 드롭다운에서 출근 전 / 근무 중 / 야근 중 / 회의 중 / 퇴근 완료 / 휴무를 직접 선택할 수 있습니다. 선택값은 `setOfficeState()`를 거쳐 실제 장면에 즉시 반영되고 `devnest.settings.actualState`에 저장되어 새로고침 후 복원됩니다. 설정 → 업무 상태의 선택값과 항상 동기화됩니다. 시간대별 배경·조명 자동 전환은 기존대로 독립 동작하며, 업무 상태 자동 판정은 아직 연결하지 않은 임시 수동 방식입니다.

## 책상 위 카메라 구도

기본 표시 방식을 `desk`(책상 위 보기)로 변경했습니다. 원본 배경의 상단 약 68.5%를 기준으로 비율을 유지해 카드 영역을 채우고, 책상 다리와 바닥은 잘라 표시합니다. 카드 비율에 따라 양옆도 일부 잘릴 수 있습니다. 이미지나 캐릭터 자산 자체는 자르거나 변경하지 않습니다.

- 오피스는 책상 위 보기로 고정합니다. 설정의 화면 섹션과 표시 방식 선택은 제거했습니다. 이전 contain/cover 저장값도 desk로 정규화합니다. 캐릭터·위젯·애니메이션 설정은 보존합니다.

## 말풍선

출근 전·근무 중·야근 중·자리 비움 회의에는 상태별 메시지 말풍선을 표시합니다. 퇴근 완료와 휴무에는 말풍선을 표시하지 않으며, 대표님 화상회의와 위치 편집 중에도 장면을 가리지 않도록 숨깁니다. 자리 비움 회의의 편집 가능한 탁상 안내판은 말풍선과 별도로 유지됩니다.

## Phase 4 — 애니메이션 엔진

기존 독립 배치·X/Y/Scale/Z-index·localStorage 저장은 구현되어 있었습니다. 이번 단계에서 `animation-engine.js`로 객체별 동작 상태·전환 정리·반복·속도·페이지 수명주기를 통합했습니다. 위치 Wrapper는 그대로 두고 내부 스프라이트 표시와 CSS 프레임 채널만 제어합니다. 프레임별 JS 타이머나 라이브러리는 추가하지 않았습니다.

### 실제 구현과 자산 부족 구분

| 객체 | 요청 동작 | 실제 표시 |
| --- | --- | --- |
| 개발자 | `idle` | 기본 정지 PNG (자동 연동에서는 설정에 따라 깜빡임 추가) |
| 개발자 | `typing` | 몸체 고정, 손 타이핑 4프레임 무한 반복 |
| 개발자 | `blink` | 기본 PNG + 실제 눈 감은 자산의 눈 영역만 반복 |
| 개발자 | `away` | 개발자 레이어 숨김 |
| 고양이 | `sleep` | 정적 수면 PNG |
| 고양이 | `breathing` | 기존 수면 움직임 4프레임 반복 |
| 고양이 | `tail` | **꼬리 전용 자산 없음**. 정적 `sleep`으로 처리 |
| 노트북 | `open` | 실버 노트북 정지 PNG |
| 노트북 | `closed` | 실제 `laptop_closed.png` 표시. 출근 전·퇴근·휴무에 자동 적용 |

`requested`와 실제 `state`, `supported`, `fallback`을 엔진 스냅샷에 별도로 기록합니다. 없는 꼬리 애니메이션은 정적 수면으로 처리합니다. 노트북은 열림·닫힘 정적 PNG를 전환하며 중간 닫힘 모션은 없습니다.

### 업무 상태 연동

- 출근 전: 개발자 `away`, 노트북 `closed` → 실제 닫힌 실버 노트북 PNG
- 근무 중: 개발자 `typing` 또는 `idle`, 노트북 `open`
- 회의 중: 개발자 `away`; 자리 비움은 노트북 `closed`, 화상회의는 별도 참가자 화면
- 퇴근·휴무: 개발자 `away`, 노트북 `closed` → 실제 닫힌 실버 노트북 PNG. 휴무 안내는 유지
- 고양이는 업무 상태와 독립적으로 `breathing` / `sleep`을 유지

### 설정과 테스트

기존 전체 ON/OFF, 정적 모드, 손·눈·고양이별 ON/OFF, 속도 0.5/1/1.5배를 유지합니다(기존 0.75/2배 프리셋도 보존). ‘캐릭터 동작 테스트’에서 객체별 동작을 선택하고 개별 테스트·자동 연동 복귀를 할 수 있습니다. 하나를 바꿔도 다른 객체의 프레임 채널을 다시 시작하지 않습니다.

동작 선택은 `animation.testActions`로 저장하며, 실제 테스트 활성은 임시 상태입니다. 새로고침에는 자동 업무 연동으로 시작합니다. 설정 닫기, 배치 편집 시작, 업무 장면 변경·미리보기 전환·종료 시 테스트를 정리합니다. 객체별 자동 연동 버튼은 해당 객체의 테스트만 해제합니다.

```js
AnimationEngine.testActor('developer', 'typing');
AnimationEngine.testActor('cat', 'sleep');
AnimationEngine.clearTests('cat'); // 고양이만 자동 연동 복귀
AnimationEngine.clearTests();
AnimationEngine.snapshot; // scene, actors, suspended, reason, testing, playing
```

### 정리와 비활성화

동작이 바뀌면 이전 CSS Animation을 취소하고 새 프레임 채널을 시작합니다. 동일 동작의 위치 변경은 프레임을 초기화하지 않습니다. 실제 카메라·크기 변경 때만 이산 프레임을 다시 맞춥니다. 반복은 `infinite`이며 속도는 자산의 원래 주기를 기준으로 적용합니다.

`visibilitychange`에서 비활성 페이지의 스프라이트·깜빡임·추가 비 효과를 중지하고 시계 갱신 타이머도 해제합니다. 활성화 시 현재 업무 상태·설정대로 복원합니다. `prefers-reduced-motion`, 정적 모드, 전체 OFF, 배치 편집은 정지 PNG를 사용합니다. 업무 상태와 저장 좌표는 바꾸지 않습니다.

### 실제 카드 수 2~8개

기본은 통합 스마트 상태·다음 일정·오늘 일정·할 일 4개입니다. 개수는 현재 오른쪽·하단에 표시된 실제 카드만 계산합니다. 오피스 내부 시계·말풍선·숨긴 카드·통합 카드 내부 항목은 별도 위젯으로 세지 않습니다.

- 통합형 스마트 상태: 시간·날씨·근무 상태를 **한 테두리 안의 1개 카드**로 표시
- 분리형 스마트 상태: 고유 파생 ID `smart_status.time`, `.weather`, `.work`의 **3개 카드**로 표시
- 분리 항목의 표시·순서·크기는 스마트 상태 그룹 설정을 따릅니다. 통합·분리 시 같은 시간/날씨/근무 DOM을 이동하므로 중복 ID나 중복 카드가 생기지 않습니다.
- 8개 통합 구성에서 분리하면 10개가 되므로 거부합니다. 먼저 다른 위젯을 숨겨야 합니다.
- 스마트 상태만 분리해 3개인 구성에서 통합하면 1개가 되므로 거부합니다. 먼저 다른 위젯을 추가해야 합니다.
- 위반 시 기존 구성을 유지하고 실제 예상 개수와 제한을 안내합니다. 설정 상단 개수가 즉시 갱신됩니다.

### 정렬·크기·반응형

설정의 ⠿ 핸들을 마우스로 드래그하거나, 핸들에 포커스 후 위/아래 방향키, 위/아래 버튼으로 정렬합니다. 상태 위젯은 오른쪽, 나머지는 하단이라는 영역은 유지하고 **각 영역 안에서** 저장된 순서대로 표시합니다. 설정에 영역 이름도 표시합니다.

small / medium / large는 하단 카드의 Grid 너비와 오른쪽 카드의 높이 비중을 조절합니다. 카드가 많아지면 배치를 촘촘하게 하되 글자를 과도하게 줄이지 않습니다. 1920×1080에서 기본 크기의 2~8개 전체 카드 틀을 한 화면에 표시합니다. 긴 내용은 카드 내부에서 스크롤합니다. 작은 화면에서 공간이 부족하면 위젯 영역 내부 스크롤 또는 모바일 세로 배치를 사용합니다. 오피스 영역의 73:27 비율과 크기는 위젯 개수로 바뀌지 않습니다.

위젯 추가 시 짧은 등장 효과, 추가·제거·정렬 시 영역의 가벼운 불투명도 전환을 사용합니다. 오피스 애니메이션과 별개이며 `prefers-reduced-motion`에서 생략합니다. 헤더는 작은 화면의 페이지 스크롤 중에도 고정됩니다.

일정·업무 메뉴에서 숨긴 위젯을 열려고 하면 해당 설정 행으로 안내합니다. 숨겨진 데이터를 초기화하거나, 상한을 무시하고 몰래 위젯을 추가하지 않습니다.

## 상태별 배치 및 휴무 안내판 (설정 버전 11)

- 설정 → 오피스 → **배치 설정 대상**에서 공통 기본 배치 또는 출근 전·근무 중·회의 중·퇴근·휴무를 선택합니다.
- 상태 선택은 미리보기이며 실제 근무 상태는 바뀌지 않습니다. 설정을 닫으면 실제 상태로 복원합니다.
- 각 상태에서 개발자·고양이·노트북의 X/Y/Scale/표시 여부/Z-index를 독립적으로 조절합니다. 위치 편집의 마우스·터치 드래그와 방향키도 선택한 상태에만 적용됩니다.
- 별도 배치가 없는 상태는 공통 배치를 따릅니다. 처음 수정하면 현재 공통 배치를 복사해 해당 상태 전용으로 저장합니다. **공통 배치 복사**는 독립 복사본을 만들고 **공통 배치 따르기**는 해당 상태의 저장 배치를 제거합니다.
- 기존 버전의 좌표는 공통 배치로 보존합니다. `stateLayouts`에는 수정한 상태만 저장하며 새로고침·리사이즈·상태 변경 후에도 유지됩니다.
- 출근 전·자리 비움 회의·퇴근·휴무에는 실제 실버 노트북의 닫힌 PNG, 근무·야근에는 열린 PNG를 표시합니다. 두 이미지는 640×336 동일 캔버스와 하단 중앙 기준점을 사용합니다.
- 휴무 안내판은 기존보다 크게 표시하며 설정의 **휴무 안내판**에서 제목(40자), 내용(200자, 줄바꿈), 크기(1~2.2배)를 변경하고 미리보기할 수 있습니다. 텍스트로만 출력하며 작은 화면에서는 카드 영역 안으로 제한합니다.
- `holidayCard`와 `stateLayouts`는 기존 `devnest.settings`에 함께 저장합니다. 저장 어댑터 분리는 유지합니다.
- 새 닫힌 노트북 원본: `source-assets/separated-inputs/laptop-closed-source.png`. 기존 실버 노트북을 기준으로 제작했으며 빌드 스크립트가 투명도 정리와 하단 정렬을 재현합니다.

검증: `python3 tests/browser_check.py` 통과. 상태별 좌표 격리·즉시 반영, 공통 배치 복사/상속, 마우스·터치 편집, 새로고침 복원, 출근 전/퇴근/휴무 닫힌 노트북, 휴무 문구·크기 저장, 기존 애니메이션·위젯 회귀 및 콘솔/리소스 오류 없음을 확인했습니다.

## 야근 상태

설정의 실제 업무 상태·상태 미리보기·배치 설정 대상에서 `overtime`(야근 중)을 선택할 수 있습니다. 타이핑·눈 깜빡임·열린 노트북을 유지하고, 기존 캐릭터 캔버스 좌표에 고정된 CSS 픽셀 다크서클과 전용 말풍선을 표시합니다. 야근 타이핑은 사용자가 선택한 애니메이션 속도에 추가로 약 1.5배 빨라집니다. 오피스 시계는 붉은색으로 바뀌고 약 1.12배 커져 야근 상태를 즉시 구분합니다. 다른 상태로 전환하면 시계 강조, 다크서클과 추가 가속이 사라집니다. 야근 배치는 다른 상태와 독립적으로 저장합니다.

설정 버전 10부터 실제 업무 상태도 `devnest.settings.actualState`에 저장합니다. 따라서 야근 중을 실제 상태로 선택하면 새로고침 뒤에도 야근 장면과 다크서클이 복원됩니다.

## 로컬 알람과 Time Timer

- 설정 → 업무 상태 → 알람에서 매일 반복할 시간, 80자 메시지와 활성 여부를 지정합니다. 시간이 되면 화면 하단 알림과 가능한 환경에서 짧은 3음 알림을 재생합니다. ‘알람 테스트’로 즉시 확인할 수 있습니다.
- Time Timer는 설정 → 위젯에서 켭니다. 5/15/25/45/60분 프리셋, 원형 잔여시간, 시작·일시정지·초기화를 제공하며 완료 시 동일한 화면 알림을 사용합니다.
- 알람과 타이머는 `devnest.productivity`에 별도로 저장됩니다. 실행 중인 타이머는 종료 시각을 저장하므로 새로고침 뒤에도 경과 시간을 이어 계산합니다. 서버나 외부 알림 서비스는 아직 사용하지 않습니다.
- 추가 파일: `frontend/js/productivity.js`. 기존 위젯 2~8개 제한, 오피스 상태와 캐릭터 위치는 변경하지 않습니다.

- 헤더의 해 모양 버튼 또는 설정 → 애니메이션의 **실내 조명 켜기**에서 즉시 전환합니다. 두 컨트롤은 동기화되며 `environment.lighting`으로 저장·복원됩니다.
- 조명 ON은 우측 구형 조명과 책상 주변에 따뜻한 광원을 더하고, OFF는 배경·캐릭터·화분을 함께 어둡게 하되 실제 UI와 안내판은 읽을 수 있게 유지합니다. 외부 이미지 교체나 무거운 필터 없이 CSS 그라디언트 한 레이어만 사용합니다.
- 배경 시간대는 `environment.timePeriod`로 저장하며 조명 ON/OFF와 독립적으로 동작합니다.

## 시간대별 오피스 베이스 이미지

- `office_dawn.png`, `office_morning.png`, `office_noon.png`, `office_sunset.png`, `office_evening.png`, `office_night.png`의 1672×941 이미지 여섯 장을 사용합니다.
- 자동 모드는 05–07시 해뜰 때, 07–11시 아침, 11–16시 점심, 16–19시 해질 때, 19–22시 저녁, 22–05시 밤 순으로 실제 배경 `src`를 교체합니다. 설정 → 애니메이션에서 각 시간대를 고정해 미리 볼 수 있습니다.
- 시간대 전환은 같은 배경 DOM 레이어의 파일만 바꾸므로 개발자·고양이·노트북·화분의 좌표와 애니메이션 상태를 다시 만들지 않습니다. CSS 색상 필터는 중복 보정을 피하기 위해 제거했습니다.
- 밤은 기존 픽셀 오피스 원본을 보존해 사용하고, 나머지 다섯 장은 같은 구도와 오브젝트를 유지한 시간대별 이미지 편집본입니다. 실내 조명 스위치는 별도 오버레이로 계속 동작합니다.

## 시간대 × 날씨 배경

- 해뜰 때·아침·점심·해질 때·저녁·밤마다 맑음(`_clear`), 흐림(`_cloudy`), 비(기본 파일명), 눈(`_snow`) 이미지를 제공해 총 24개 조합을 표시합니다.
- 설정 → 애니메이션 → **날씨 배경**에서 맑음·흐림·비·눈을 선택합니다. `environment.weatherType`에 저장되며 새로고침 후 복원됩니다. 향후 날씨 API는 이 값만 갱신하면 같은 렌더링 경로를 재사용할 수 있습니다.
- 스마트 상태의 날씨 문구와 아이콘도 선택값에 맞춰 바뀝니다. 실제 온도·예보 API는 아직 연결하지 않았습니다.
- **날씨 효과 활성화**는 베이스 이미지를 바꾸지 않고 창문 안쪽 마스크의 움직이는 비·눈 효과만 제어합니다. 맑음과 흐림에는 강수 애니메이션을 표시하지 않습니다.

## 나의 독서 책장

- 오피스 왼쪽 책장을 클릭하면 연도별 `MY READING TRACKER`가 열립니다. 참고한 종이 책장 도안처럼 기본 48개의 빈 아이보리 책등을 제공하고, 완독 기록을 추가하면 선택한 색으로 책등이 채워집니다.
- 책등에는 제목을 세로로 표시하며 클릭하면 제목·저자·완독일·평점·책등 색상·한줄평을 수정하거나 삭제할 수 있습니다. 완독일의 연도에 따라 각 연도 책장으로 자동 분류됩니다.
- 실제 오피스의 왼쪽 책장은 완전히 투명한 히든 클릭 영역입니다. 마우스 hover·클릭·키보드 focus에도 테두리, 배경, 툴팁, 완독 권수나 책 미리보기를 표시하지 않습니다. 접근성 이름과 클릭 기능은 유지하며 위치 편집과 화상회의 중에는 비활성화됩니다.
- 데이터는 오피스 설정과 분리된 `devnest.readingShelf.v1` localStorage에 최대 240권까지 저장합니다. 아직 외부 도서 API나 계정 동기화는 연결하지 않았습니다.

## 설정 탭

설정은 배치 / 업무 상태 / 모션 / 연동 / 위젯의 한 줄 5탭으로 구성됩니다. 별도 안내판 탭은 업무 상태 안의 접이식 항목으로 합쳤습니다. 배치는 `장면 선택 → 오브젝트 선택 → 화면에서 직접 배치 켜기 → 장면에서 드래그` 순서로 사용합니다. 기본 화면에는 선택한 오브젝트의 크기 슬라이더와 표시 여부만 노출하고 X/Y/Scale 숫자와 앞뒤 순서는 ‘숫자로 정밀 조정’에 접어 둡니다. 오브젝트를 장면에서 클릭해 선택하거나 방향키로 미세 이동할 수도 있습니다. 상태별 복사·공통 배치 전환도 고급 항목입니다. 말풍선 메시지·휴무 안내판·캐릭터 동작 테스트·세션 비밀키 역시 필요할 때 펼칩니다. 탭과 저장 상태는 고정되며 내용 영역만 스크롤됩니다. 좌우 방향키와 Home/End로 탭을 선택할 수 있고 탭 전환은 기존 설정·위치 편집·미리보기를 변경하지 않습니다.

설정 탭 클릭 문제 대응: 탭 초기화를 `frontend/js/settings-tabs.js`로 분리해 저장소·애니메이션 초기화에 의존하지 않도록 했으며 CSS/JS URL에 버전을 추가했습니다. 현재 Chrome에서는 증상이 재현되지 않았고, 1920×1080·1024×768·390×844에서 실제 마우스 클릭의 히트 테스트, 모든 탭 전환, 안내판 미리보기, 편집 ON/OFF, 닫기 및 기존 회귀 테스트를 통과했습니다. 캐시가 원인인지는 사용자 브라우저에서 추가 확인이 필요합니다.

설정 패널은 데스크톱·태블릿에서 앱 Grid의 오른쪽 열을 사용하는 사이드바입니다. 열면 대시보드가 남은 폭에 맞춰 줄어들며 서로 겹치지 않습니다. 700px 이하에서는 헤더 다음 행에 설정을 배치하고 오피스와 위젯을 아래로 밀어 콘텐츠를 가리지 않습니다. 세 화면 크기에서 실제 경계가 겹치지 않는지 브라우저 검사로 확인했습니다.

## Dashboard ↔ Virtual Office

- 상단 메뉴 제거 후 Virtual Office 진입은 픽셀 오피스 왼쪽 선반의 주황 캐릭터가 담당합니다. 주황 캐릭터는 장면을 가리지 않는 투명 클릭 영역을 사용합니다.
- 기존 대시보드 DOM은 제거하거나 다시 렌더링하지 않고 0.4초 픽셀 스텝 전환으로 숨깁니다. 돌아오면 위젯 설정, 캐릭터 위치, 업무 상태와 애니메이션 인스턴스가 그대로 유지됩니다.
- 임시 화면의 **내 오피스로 돌아가기** 또는 `Esc`로 대시보드에 복귀합니다.
- `VirtualOfficeNavigation.view`와 `connection: "offline"`은 `OfficeState`와 별개입니다. 현재 화면은 로컬 미리보기이며 실제 서버 접속·인증·멀티플레이 기능은 구현하지 않았습니다.

## 시간대 배경과 조명

- 기본값은 현재 기기 시각을 따르는 자동 모드입니다: 해뜰 때 `05:00–07:00`, 아침 `07:00–11:00`, 점심 `11:00–16:00`, 해질 때 `16:00–19:00`, 저녁 `19:00–22:00`, 밤 `22:00–05:00`.
- 설정의 애니메이션 탭에서 자동 모드 또는 여섯 시간대를 직접 선택해 미리볼 수 있으며 선택값은 다른 오피스 설정과 함께 저장됩니다.
- 기존 픽셀 오피스 자산을 유지하면서 창문 색감, 배경 밝기, 자연광과 램프 광량만 CSS로 전환합니다. 상단 조명 버튼은 시간대와 별개인 전체 조명 마스터 스위치입니다.

## 연동·개인정보 설정

- 설정의 **연동** 탭에서 표시 이름, 이메일, 시간대, FastAPI 주소, Google Calendar ID, GitHub 사용자명과 날씨 지역을 입력할 수 있습니다. 이 일반 정보는 현재 브라우저의 `devnest.settings`에 저장됩니다.
- Google API 키, GitHub 토큰, 날씨 API 키와 사용자 API 키는 페이지 메모리에만 보관하며 `localStorage`에 기록하지 않습니다. 새로고침하거나 탭을 닫으면 폐기됩니다.
- 아직 외부 요청이나 인증은 수행하지 않습니다. FastAPI 연동 시 비밀값 입력 부분을 서버 측 보안 저장 방식으로 교체해야 합니다.

## 로그인 화면 (미리보기)

`/login.html` 또는 대시보드 헤더의 ‘로그인’ 링크로 확인합니다. 이메일·비밀번호 입력, 비밀번호 표시 전환, 준비 중 안내와 대시보드 복귀를 제공합니다. 인증/API 연결과 입력 정보 저장은 없으며, 기존 대시보드는 로그인 없이 계속 사용할 수 있습니다.
