## 실제 적용 범위

[ASSET_SPEC.md](ASSET_SPEC.md)는 코드의 좌표/크기/pivot/깊이/줌을 설명합니다. [lobby-assets.md](lobby-assets.md)는 등록·교체·새 입구·폴백·ARM64 배포와 미확보 최종 이미지 목록을 설명합니다. 추가된2개 PNG는 자체 코드 제작1차 아트이며 최종 디자인 완성으로 보고하지 않습니다. 기존 아바타와 가구 원화3개 PNG는 재사용했습니다. 전체 이미지 한 장을 배경으로 쓰지 않았습니다.

현재 로비는 목재 바닥/석재 홀, 두 방향 후면 벽, 입구7종, 기둥과 기존 소파/화분/램프를 독립 요소로 렌더링합니다. A*/좌표 변환/이동/충돌 알고리즘은 변경하지 않았으며 장식의 footprint만 공유 맵에 추가했습니다. 기존 RoomManager·입장/퇴장·서버 권한 검증은 수정하지 않았습니다. 다른 룸·개인 집의 맵 데이터와 가구/코인 서버 로직도 유지했습니다.

하단은 기존 조작 안내와 화면 모드 전환을 유지합니다. 신규 캐릭터 감정 표현 전송/애니메이션은 구현하지 않았습니다. 전용 안내 데스크, 최종 모서리 캡/벽 장식, 최종 테마 입구 및 조명PNG는 미확보이며 제작 순서는 에셋 가이드에 기록했습니다. Raspberry Pi 실기기/15개 실제 브라우저 동시 성능은 검증하지 않았습니다. 서버 처리와 클라이언트 렌더링 성능을 혼동하지 않습니다.
