# 멀티채널 사용자·관리자 흐름

1. 개발용 닉네임 또는 기존 ID/비밀번호 로그인 → 마지막 채널의 단일 Office World. 상단에서 채널/접속 수/정원을 확인합니다.
2. 바닥 클릭·터치로 존을 걸어서 이동합니다. 경계에 따라 현재 존 채팅이 바뀌며 같은 채널의 사용자만 보입니다. 좌측에는 서비스 메뉴만 둡니다.
3. 상단 채널 선택 → 서버 정원 검사 → 이전 채널 퇴장/대상 채널 입장. 근무 상태를 유지하고 채널별 이전 위치를 복원합니다. 정원이 차면 기존 채널에 남습니다.
4. 월드/채널/현재 존 탭으로 공개 대화 범위를 선택합니다. @닉네임 자동완성에서 ID를 골라 귓속말을 보냅니다. 다른 채널도 전달되며 오프라인은 보관 후 재접속 시 복원합니다. 중복 닉네임을 임의로 선택하지 않습니다.
5. 설정 → 공개 채팅 말풍선 ON. 카페/라운지 등 허용 존의 공개 메시지만 잠시 표시합니다. 집중/회의실/개인 집에서는 채팅 말풍선을 표시하지 않습니다. 상태 메시지는 별도입니다.
6. 초대 카페/회의는 기존 생성·초대·수락·종료 흐름입니다. 비공개 본문은 비참여자나 관리자에게도 노출하지 않습니다. 개인/그룹 비공개 대화는 귓속말 UI와 구분합니다.
7. 관리자가 전체/채널 공지를 발송 → 대상 사용자 상단 토스트 큐 → 자동/수동 닫기 → 공지 기록. 채팅 전용 모드에도 표시합니다.
8. 라운지 책장 접근 → 내 집 → 기존 가구 배치·회전·회수·저장·구매·코인 내역·DevNest PC 왕복. 집 출입문 → 기존 오피스 위치 복원. 집에서는 채널을 바꾸지 않습니다.
9. 서버 운영자는 기존 계정 ID를 list-users로 확인하고 최초 한 번 bootstrap-admin CLI를 실행합니다. 기존 계정 비밀번호로 로그인 → /admin.
10. 관리자 메뉴: 접속 현황/채널/공지/사용자/권한/신고/공개 채팅/감사 로그. super_admin만 관리자 임명과 중요 설정을 변경합니다. 일반 사용자는 관리자 접근 거부 화면을 봅니다.

소셜 그룹·기록·사진·영상, 실제 결제/게임 보상, 타인 집 방문은 미구현입니다. PostgreSQL 연결은 Phase 3.5에 추가했습니다. 현재 장비를 운영 서버로 간주하지 않으며 README의 별도 이전 절차를 따릅니다.

## Phase 3.5 화면 흐름

1. 로그인 → 아이콘 사이드바·확대된 Office World. ☰는 메뉴 고정/접기를 저장하며 호버는 겹쳐 펼쳐집니다. 존 이동 메뉴는 없습니다.
2. 바닥 클릭/탭은 이동, 드래그/휠/핀치는 카메라 탐색입니다. 전체 보기·내 캐릭터 복귀는 좌표를 바꾸지 않습니다.
3. 모바일은 상단 최소 헤더·중앙 월드·하단 월드/채팅입니다. 채팅 선택 시 전체 채팅 화면과 입력창을 유지하고 캔버스를 멈춥니다. 다시 월드로 돌아와도 위치가 유지됩니다.
4. 닉네임·고정 상태·임시 채팅을 따로 배치하고 화면 경계/다중 사용자 겹침을 보정합니다. 금지 존·비공개 말풍선 규칙은 유지합니다.
5. 접속 정원이 찬 채널은 안내 후 상단에서 다른 활성 채널을 선택합니다. 저장 채널이 비활성이면 기본 채널의 안전한 위치로 입장합니다.
6. 관리자 대시보드에서 집계·채널 인원·환경·계정 출처·최근 공지/작업을 확인합니다. 운영 로그는 이름과 KST, 펼친 상세는 원본 UTC JSON입니다.
7. DevNest는 환경별 기본 URL 또는 사용자 설정을 사용합니다. 팝업 차단은 오류를 표시하고 재시도/주소 설정으로 연결합니다. 외부 페이지 자체의 접속 오류는 새 탭과 안내에서 확인합니다.

## Phase 4 아케이드 흐름

1. 라운지 게임기 클릭(또는 서비스 메뉴의 미니게임) → 기존 A* 접근 → NOBIS 아케이드 로비. 준비된 두더지 잡기만 시작할 수 있습니다.
2. 서버가 시작 승인·세션 발급 → 중앙 3×3 보드·남은 시간·서버 점수. 캐릭터는 원래 오피스 위치에 머물고 동료에게 게임 중 상태를 표시합니다.
3. 클릭/모바일 터치 → 현재 두더지 challenge를 서버에 전송 → 명중 판정/점수 갱신. 빈 칸·늦은 입력은 점수를 올리지 않습니다.
4. 채팅·귓속말·공지 연결은 계속 유지합니다. 모바일 월드/채팅 전환을 그대로 사용할 수 있으며 게임의 30초 서버 시간은 계속 흐릅니다.
5. 시간 종료 → 원장/잔액/결과 한 번 정산 → 결과 화면. 실패하면 성공 문구 대신 재시도와 사유를 안내합니다. 중도 종료는 보상0입니다.
6. 다시 플레이 또는 오피스 복귀. 원래 위치·근무 상태를 유지합니다. 개인 집으로 들어가 기존 상점에서 게임으로 얻은 Coin을 사용합니다.
7. 로비 내 게임 기록에서 최고 점수·횟수·누적 보상·최근 기록을 확인합니다.
8. /admin 게임 설정·보상 내역·이용 현황·검증 기록. 권한 검사는 서버에서 수행하고 설정/지급을 기존 감사 로그에 남깁니다.

## Phase 5 — 친구부터 그룹 기록까지

1. 상단 소셜 아이콘 → 사용자 검색 → 프로필 → 친구 요청. 수신자는 소셜 알림/친구 목록에서 수락/거절합니다.
2. 내 그룹 → 그룹 만들기(기본 비공개) → 그룹 멤버·관리 → 사용자 ID 초대. 상대는 내 그룹에서 수락합니다. 공개 그룹은 목록에서 가입 요청 후 승인받습니다.
3. 그룹 피드 → 글·사진·공개 범위 선택 → 게시. 멤버는 댓글/이모지로 반응합니다. ‘나만 보기’는 작성자에게만 보입니다.
4. 다른 월드 채널 또는 오프라인에서도 같은 그룹 데이터를 사용합니다. 알림을 누르면 해당 그룹 피드로 이동합니다. 탈퇴/강퇴 시 피드/사진 권한이 회수됩니다.
5. 공개 설정 → 자기소개·상태·접속·업무 상태·위치 공개 범위 저장. 다른 사용자 프로필은 서버가 허용한 필드만 보입니다.
6. 글/댓글/사용자 신고 → /admin 소셜 신고 → 해당 신고 대상만 검토 → 숨김/처리 메모. 비공개 그룹 전체 접근은 제공하지 않습니다.

## 출석 → 무료 티켓 → 집 가구

1. 상단 티켓 아이콘 → 오늘 상태·KST 달력·연속/누적 출석·티켓 잔액 확인 → 출석 보상 받기. 같은 날 재요청은 추가 지급하지 않습니다.
2. 가구 뽑기 → 배너와 아이템별/등급별 확률 확인 → 1회 또는 5회 선택. 티켓 부족 시 비활성화합니다.
3. 서버 영수증 수신 → 짧은 결과 연출(건너뛰기 가능) → 등급·가구 표시. 집 인벤토리에 지급합니다. 네트워크 불명확 시 같은 요청 재시도, 확률 변경 시 재확인을 안내합니다.
4. 뽑기·티켓 기록 → 기존 확률표 버전과 지급/사용 내역 확인. 출석은 근태/성과와 무관한 선택 보상입니다.
5. /admin 출석·가챠 운영 → 보상·배너·확률/풀 설정, 무료 티켓 지급, 통계/기록 조회. 현금 결제/거래 UI는 없습니다.

데스크톱은 기존 월드 위 모달, 390px 모바일은 화면 폭 안의 모달로 표시합니다. 모달 동안 월드 입력/렌더링을 쉬고 WebSocket·채팅은 유지합니다. 좌측 존 버튼과 WASD는 추가하지 않습니다. 실제 캡처는 phase5-*.png 및 Phase 5 검증 문서에 연결합니다.

## 현재 코인 뽑기 흐름(v8)

티켓 아이콘 → 코인 뽑기 → 분포 그래프와 금액별 확률 확인 →1회/5회 → 서버 확정 Coin 결과/합계 → 기존 Coin 잔액/거래 내역 갱신. 기존 가구 기록은 과거 영수증에서 조회하며 신규 보상은10~1000 Coin입니다. 관리자는 코인 금액별 확률을 편집하거나 정규분포형 기본값으로 복원합니다.

## Phase 6 — 친구와 활동

소셜 아이콘 → 친구와 활동 → 집 방문/2인 협동 게임/가구 도감/선택 공유.

- 집 주인이 공개 범위 저장 → 친구 프로필에서 방문 요청 → 받은 요청 승인/거절 → 방문자 입장 → 같은 집 아바타·채팅·배치 공유 → 집 문/복귀 버튼. 소유자는 내보내기, 방문자는 신고가 가능합니다. 기본 private, 친구 모드도 승인 필요, 승인24시간, 소유자 포함 최대5명입니다.
- 친구 프로필에서 협동 게임 초대 → 상대 수락 → 번갈아 두 장 →6쌍 완료 → 참가자별 결과/Coin 표시. 숨겨진 카드는 서버에서 공개하지 않습니다. 제한5분·재접속 유예30초, 취소/만료/연결 종료는 보상 없이 종료합니다.
- 도감: 상점 구매·기존 보유 가구의 수량/설치/최초 획득/경로/진행률. 가챠 전용 가구·의상 분류를 만들지 않습니다.
- 공유할 보유 가구/게임 결과/진행률 선택 → 그룹 선택 → 미리보기 → 명시적 게시. 자동 게시하지 않습니다.
- 티켓 → 기존 코인 가챠 → 코인 지갑 → 가구 상점 → 인벤토리 → 집 배치. 가챠 화면에서 누적 획득 Coin도 확인합니다.
- 관리자 협동 게임·집 방문 메뉴는 진행/종료/이상 입력·지급 원장·방문 신고를 표시하며 보드 정답/비공개 대화를 노출하지 않습니다.


## Phase 7 — 첫 비주얼 적용

1. 로그인: 원본 픽셀 로고와 독립 SVG 가구/바닥/아바타 장면, 기존 인증 흐름.
2. 오피스: 접을 수 있는 서비스 메뉴, 넓은 단일 월드, 우측 상태/채팅. 여섯 존은 같은 월드의 색·바닥 패턴으로 구분합니다.
3. 클릭/터치 이동: 기존 길찾기를 따라 실제 아바타 walking → idle. 책상/의자는 접근 후 typing/sitting 포즈입니다.
4. 개인 집: 기존 입구 접근 → 집. 가구 선택/회전/배치 ghost와 상점 썸네일이 같은 픽셀 에셋을 사용합니다.
5. 소셜·미니게임·출석·코인 가챠·관리자: 공통 표면/버튼/탭/모달. 가챠 결과는 서버 확정 Coin이며 동작 줄이기와 건너뛰기를 유지합니다.
6. 모바일: 월드/채팅 전환, 채팅 전용에서는 게임 렌더링 중지. 작은 화면에서도 출석/가챠·기존 소셜 화면을 사용할 수 있습니다.

[현재 캡처와 검증](phase7-verification.md). 최종 손그림 원화와 이미지 타일셋은 아직 확정하지 않았습니다.


## Phase 7-A · 새 이동 흐름

메인 입구에서 입장 → 넓은 중앙 라운지 → 각 방의 문/연결로/계단으로 이동합니다. 카페는 좌상단,회의실은 상단 중앙,옥상 정원은 우상단,집중존은 좌측,휴식 공간은 우측,휴가 정원은 좌하단,외근 테라스는 우하단입니다. 줌아웃하면 크기가 다른 다각형 방과 연결로를 함께 확인할 수 있습니다.

라운지 책장에 걸어가 기존 메뉴로 내 집 인스턴스에 들어가고 기존 문/복귀 기능으로 돌아옵니다. 클릭 이동·현재 존·채팅 채널 갱신은 같은 Scene에서 수행합니다. [실제 배치도](phase7a-layout.svg),[브라우저 화면](phase7a-asymmetric-overview.png).
