# 현재 사용자 흐름 — Hybrid World

현재 기준은 [Hybrid World 설계](hybrid-world.md)와 [검증 기록](hybrid-verification.md)입니다. 이전 단일 맵 문서는 [이전 기록](history/before-hybrid-storyboard.md)으로 보존합니다.

로그인 → 로비 → 입구 클릭 → 자동 보행 → 서버 입장 검증 → 독립 룸. 출입문 클릭 → 로비 해당 입구. 회의 입구 → 참석 가능한 회의 목록 → 권한 확인 후 입장. 개인 집 입구 → 기존 내 집/방문/꾸미기. 미니게임 메뉴 → 라운지 게임기까지 보행.
