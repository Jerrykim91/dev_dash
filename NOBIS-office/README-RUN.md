# NOBIS Office 실행 방법

현재 개발 Mac에서 실행하는 방법입니다. 프로젝트 위치는 다음과 같습니다.

```text
/Users/hyowonkim/Desktop/Demo/Projects/NOBIS-office
```

## 1. 실행하기

터미널에서 **아래 한 줄을 그대로 실행**하세요. 현재 어떤 폴더에 있든 사용할 수 있습니다.

```bash
/Users/hyowonkim/Desktop/Demo/Projects/NOBIS-office/start-frontend.command
```

Finder에서 프로젝트 폴더의 **`start-frontend.command`를 더블클릭**해도 됩니다.

이름은 `start-frontend`이지만 다음 두 서버를 함께 확인합니다.

- 백엔드가 꺼져 있으면 먼저 실행합니다.
- 프런트엔드가 꺼져 있으면 실행합니다.
- 이미 실행 중인 NOBIS 서버는 그대로 사용합니다.
- 프로젝트 안의 `.tools/node`에 설치된 Node.js와 npm을 우선 사용합니다.

터미널에 아래 주소가 표시되면 브라우저를 여세요.

```text
NOBIS Office: http://127.0.0.1:15173
```

**서버를 실행한 터미널 창은 켜 두세요.** 명령어 끝에 `\`를 붙이지 마세요.

## 2. 접속하고 로그인하기

1. [노비스 오피스 열기](http://127.0.0.1:15173)
2. 개발용 닉네임을 입력합니다.
3. **오피스 입장하기**를 누릅니다.

기존 세션으로 자동 접속될 수도 있습니다. 새로 실행한 로컬 백엔드는 개발용 로그인을 사용합니다.

| 용도 | 주소 |
|---|---|
| 노비스 오피스 화면 | http://127.0.0.1:15173 |
| 백엔드 상태 확인 | http://127.0.0.1:18000/health |
| 화면에서 사용하는 API 연결 확인 | http://127.0.0.1:15173/api/health |

상태 확인 주소에서 `"status":"ok"`가 나오면 API가 응답하고 있습니다.

## 3. 종료하기

실행한 터미널에서 **`Ctrl+C`**를 누릅니다.

이 실행 파일이 새로 시작한 서버만 종료합니다. 다른 터미널에서 이미 실행 중이던 서버를 재사용했다면, 해당 서버는 원래 터미널에서 따로 종료해야 합니다.

## 4. 다시 실행하기

같은 명령을 다시 실행하고 브라우저를 새로고침하세요.

```bash
/Users/hyowonkim/Desktop/Demo/Projects/NOBIS-office/start-frontend.command
```

기존 DB를 삭제하거나 다시 만들 필요는 없습니다.

## 5. 오류 해결

### `zsh: command not found: npm`

위의 `start-frontend.command`로 실행하세요. 이 파일이 프로젝트 내부 Node.js 경로를 자동으로 설정합니다. 터미널에서 `npm`을 직접 입력할 필요가 없습니다.

현재 PC의 설치 파일은 `.tools/node/bin/node`이며, `.tools`는 Git에 포함하지 않는 로컬 폴더입니다. 다른 PC로 소스만 복사했다면 Node.js와 Python 환경을 별도로 준비해야 합니다. 설치 방법은 [메인 README의 로컬 개발 설치](README.md#로컬-개발-설치)를 참고하세요.

### 화면에 ‘서버에 연결할 수 없어요’가 표시됨

1. 위 실행 명령을 실행하고 터미널에 오류가 없는지 확인합니다.
2. [백엔드 상태](http://127.0.0.1:18000/health)와 [API 연결 상태](http://127.0.0.1:15173/api/health)를 확인합니다.
3. 브라우저를 새로고침합니다.

화면만 열리고 백엔드가 꺼져 있어도 이 오류가 발생합니다. 실행 파일은 꺼져 있는 백엔드를 자동으로 시작합니다.

### `Port 15173 is already in use` 또는 `address already in use`

기존 실행 터미널과 접속 주소를 먼저 확인하세요. 같은 앱이 이미 켜져 있다면 기존 화면을 사용하면 됩니다. 포트를 사용하는 다른 프로그램을 임의로 종료하지 말고, 필요 없는 실행 창을 확인한 뒤 종료하세요.

## 데이터와 운영 환경

기본 로컬 DB는 `backend/data/nobis.sqlite3`입니다. `DATABASE_URL`을 별도로 설정한 경우에는 그 DB가 우선합니다. 실행 파일은 기존 데이터를 초기화하지 않습니다.

이 안내는 현재 Mac의 **로컬 개발 실행** 기준입니다. Docker·PostgreSQL 설치, 백업·복구, 최종 운영 서버 이전은 [메인 README](README.md)를 참고하세요.
